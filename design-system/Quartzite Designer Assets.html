quartzite designer — asset set

The shippable asset set for the Quartzite Designer application, mirroring the framework's file conventions in the parent design-system project. Mark variants (light / dark / white-halo), full primary lockup wordmark, and rasterized PNG ladders at every common size.

Mark · SVG variants

Three mark variants. Light has an explicit white background; dark is transparent (paints on dark surfaces directly); the white variant adds a 3·px halo for legibility on colored backgrounds.
