Proposed change vs framework today.
Current DefaultStyle::paint<TextEdit> overlays Window.with_alpha(0.5), which on the default palette renders white-on-white and is indistinguishable from the writable state. This card instead tints with WindowText.with_alpha(0.10) and drops text alpha to 0.65 — both derive from ColorRole slots, both produce a visible read-only state on every palette. Recommend updating the overlay in default_style.rs to match.
