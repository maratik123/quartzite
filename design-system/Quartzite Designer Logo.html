quartzite-designer · logo system

quartzite designer

Lockups and an application icon for the Quartzite Designer app, built on the existing brand mark. The mark, color tokens (#0080FF / #1E90FF) and type stack (DejaVu Sans / DejaVu Sans Mono) are inherited verbatim from the design system. Everything below uses only the system's primitives: 1 px black or Mercury strokes, integer-pixel geometry, zero rounded corners, no shadows, no gradients.

Primary lockup

Mark + stacked wordmark. "quartzite" in DejaVu Sans Regular 28·px; "designer" tucked beneath in 12·px medium uppercase, tracked +2.4·px, set in Highlight blue. The accent labels the application without changing the brand's typographic voice.
