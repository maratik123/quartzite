## Technical constraints

- **Filesystem rename** is `git mv .claude/skills/code-review .claude/skills/project-review` — preserves git history for the SKILL.md file (`git log --follow` proves the chain).
- **`description:` frontmatter** in the two agent files (`review-findings.md`, `self-review.md`) is end-user-visible text shown by the agent-card UI; the rename must keep the description grammatical (not just substring-replace the token — re-read each sentence after the substitution).
- **The Propagation Rule rows in AGENTS.md** themselves describe the Review group's sync requirement — after the rename, the three Review-group rows must name the post-rename file path `.claude/skills/project-review/SKILL.md`.
- **`.claude/settings.local.json` allow-list entries** are **gitignored** (`.gitignore` line 3) — local user-machine state, not tracked. The two entries reference dead historical paths (`2026-05-06-code-review.progress.md`). The on-disk rewrite is cosmetic — neither path exists on disk, and because the file is gitignored the rewrite does NOT enter the PR diff — but keeping the local allow-list aligned with the post-rename naming convention prevents future grep-noise on the owner's machine. AC13 verifies the on-disk content via `grep`, independent of git tracking.
- **`.claude/skills/context-reset/SKILL.md`'s canonical anchor** `## Compaction recovery (re-entry)` is referenced by other skills — anchor text MUST NOT change; only the `code-review` token mentions inside the surrounding body change.
- **`ai-docs/templates/progress-format.md`** is the canonical schema source for `.progress.md` files; renaming path examples here is the canonical change, not an instance.
- **`AGENTS.md` size** — baseline `wc -c AGENTS.md` is 35,795 chars at spec time (within the 35k–40k proactive band, well under the 40k hard cap). The rename adds +12 chars (`code-review` → `project-review`, +3 chars × 4 hits) → 35,807 chars post-rename. Not gated by an AC in this PR (see Key decisions row for AC10 drop); the 35k–40k extraction pass is `/ai-audit`'s concern.
- **No file is added or deleted** beyond the implicit `git mv` (directory rename). The diff is rename-plus-edit only.
