# Design: squeeze `AGENTS.md` and `ai-docs/context.md` below the perf threshold

**Issue:** #497
**Spec:** `ai-docs/plans/2026-05-20-squeeze-agents-context-size.spec.md`
**Date:** 2026-05-20

## Approach

Two source files cross the 35,000-char early-warning band — `AGENTS.md` at 37,673 chars (needs ≥ 2,674 chars cut) and `ai-docs/context.md` at 43,351 chars (needs ≥ 8,352 chars cut). Both shrinks reuse the PR #324 / PR #201 model the project has already validated twice: extract verbose subsections into `ai-docs/<topic>.md` reference pages with anchored back-links; collapse AXIOM-plus-redundant-prose duplications; collapse repeated table rows. No binding rule loses verbatim wording — every `> **AXIOM …**` blockquote, every `**MUST** / **NEVER** / **DENY** / **ASK**` directive, and every action table relocates with its full body intact, plus an anchored link from the source file when extracted.

### `ai-docs/context.md` strategy (~8,352-char gap)

Single primary extraction is sufficient and matches the spec's pre-resolved decision. `### Maintenance plans (cross-cutting)` is 15,926 chars of long bullet narrative; lifting the bullet body into a new `ai-docs/plans-summary.md` (analogous to `ai-docs/key-decisions.md`) leaves the H3 heading in place (preserves the inbound anchor `context.md#maintenance-plans-cross-cutting` from `ai-docs/plans/INDEX.md:160`) plus a one-line pointer paragraph. Expected post-extraction size of `context.md` ≈ **27,500 chars** — well under the 35k band with > 7k headroom. No other context.md section needs cutting; the H2 skeleton (`## Purpose`, `## Crate Layout`, `## Concept Mapping`, `## Out of Scope`, `## Core Architecture`, `## Key Design Decisions`, `## Plans (Implementation Order)`, `## Open Questions`) stays as-is.

### `AGENTS.md` strategy (~2,674-char gap)

Three candidates listed in the spec (`## Workflow`, `## Learning Log`, `## Propagation Rule`). Sensible default per the spec's *Key decisions*: prioritise mechanism (b) (AXIOM-vs-redundant-prose dedup) and mechanism (c) (table-row collapse) before mechanism (a) (new extraction destinations), to minimise new files. The two existing destination pages — `ai-docs/workflow.md` (1,484 chars, intro + GraphQL PR-comment-resolution recipe) and `ai-docs/corrections-log.md` (13,621 chars, Boundary-rule exception bodies + entry-format glossary + FORBIDDEN-skip table) — are the natural homes for any extracted prose; new reference pages are not needed for AGENTS.md.

### Rejected alternatives

- **Rewording AXIOMs to be shorter.** Spec explicitly forbids ("`MUST` stays `MUST`; `NEVER` stays `NEVER`…"). The PR #324 precedent did not touch AXIOM wording, and the cost-of-rewording risk (binding-rule semantic drift) is unbounded.
- **Restructuring H2 ordering of either file.** Spec out-of-scope: "Restructuring the H2 section ordering of either file. Sections may be shortened or have content moved out, but the H2 skeleton stays so existing memory of `look in '## Workflow'` / `look in '## Key Design Decisions'` continues to resolve."
- **Splitting `### Maintenance plans` into multiple H3 subsections inside `context.md`** (rather than extracting). Net char savings are negative — section headers and inter-section blank lines add overhead while the bullet bodies stay.
- **Two new reference pages for AGENTS.md** (e.g., `ai-docs/workflow.md` plus a separate `ai-docs/learning-log.md`). Rejected: `ai-docs/corrections-log.md` already exists for this exact extraction shape (PR #324) and is topically correct.
- **Extracting `## Code Style` further.** Spec calls it out as already-optimal ("`## Code Style` section (~4,545 chars) already follows the extraction pattern and is treated as optimal — no further cuts.").
- **Extracting `## Build & Test`.** 4,026 chars; contains two AXIOMs (`actionlint` + 40k-cap) both of which carry their own decision tables. The adjacent stand-alone Search bullet (line 71) is a one-liner; no meaningful prose-dedup target. Skipping.
- **Removing the Propagation-Rule see-also rows entirely** (i.e., collapsing the Task/Design group to a single row with no per-file lookup). Rejected: agents grep this table by source-file path; removing the per-file rows breaks lookup for an agent that types `grep -n '.claude/agents/design-review.md' AGENTS.md`. The see-also row preserves the path-keyed lookup while removing the duplicated target-file column.

## Risks

- **Char-cut shortfall on AGENTS.md.** Mitigation: Per-section allocation budgets 3,800 chars of cuts against a 2,674-char gap (~1,100-char safety margin). If a section underperforms, the fallback move is to lift more of the multi-bullet block at AGENTS.md lines 144–162 into `ai-docs/workflow.md` (the `git commit --no-verify` rule and the *Plan first / Tests before prod code* line are the next compressible bullets if needed). The AXIOM blockquotes themselves remain off-limits for shrinkage.
- **Inbound anchor breakage.** Two known inbound anchors: `code-style.md:108 → AGENTS.md#api-naming` (out of extraction set; safe) and `INDEX.md:160 → context.md#maintenance-plans-cross-cutting` (mitigated by Task 2's heading-preservation requirement; Task 9c re-verifies). Plus 28 reference-page intro back-links (`workflow.md:3`, `api-naming.md:3`, `corrections-log.md:3`, `agent-docs-index.md:3`, `dependency-versions.md:3`, `corrections-log.md:49`) — all point at H2-level AGENTS.md anchors (`#workflow`, `#api-naming`, `#learning-log`, `#agent-docs`, `#dependency-versions`) that the spec's H2-preservation rule explicitly protects.
- **Boundary-rule Exception drift after collapse.** Risk that the one-line stub in AGENTS.md and the full body in `corrections-log.md` diverge over time. Mitigation: stubs always include the anchored link; future edits to either side fire the Propagation Rule for the Learning-Log group (already encoded in AGENTS.md `## Propagation Rule` table row at line 216, which itself stays verbatim).
- **`corrections-log.md` is itself nearing the 35k band.** Currently 13,621 chars — well below the cap, so absorbing the 2,100-char Boundary-rule shrink contents is not a regression risk. Task 5 explicitly *verifies* the mirror exists rather than rewriting it, so no new content lands in `corrections-log.md` from this PR — the size stays at 13,621 chars.
- **PR# divergence between AGENTS.md and `corrections-log.md` for the compaction-recovery retro-tag** (AGENTS.md line 294 cites PR #492; `corrections-log.md` line 19 cites PR #492 too — verified to match in Task 5).
