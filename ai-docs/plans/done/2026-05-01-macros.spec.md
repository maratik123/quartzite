# Macro System

**Source:** AI design dialogue (tmp/qt_01..14.log)
**Date:** 2026-05-01

## Scope

Implement `quartzite-macros` — a proc-macro crate. All macros operate on syntax only (no type resolution at macro-expand time).

### `#[derive(Extend)]` with field attributes `#[root]`, `#[base]`, `#[mixin]`

Handles object hierarchy composition. Decision tree:

| `#[root]` | `#[base]` field | `#[mixin]` fields | Output |
|---|---|---|---|
| yes | none | any | Top-level root: generates `As{TypeName}` trait (no supertrait) + self-ref impl |
| yes | one | any | New hierarchy level: generates `As{TypeName}: As{ParentType}` trait + self-ref impl + delegation impls for parent and all ancestors + leaf impls for mixins |
| no | one | any | Concrete type: generates delegation impl for parent trait + all ancestors + leaf impls for mixins |
| no | none | ≥1 | Standalone capabilities: leaf impl per mixin only |
| no | none | none | **Compile error** — must have `#[root]`, `#[base]`, or `#[mixin]` |
| any | ≥2 | any | **Compile error** — at most one `#[base]` field |

Ancestor propagation: when `#[base] widget: WidgetBase` is found, macro derives type name → `AsWidget`, generates `impl AsWidget for Self`. The parent type must already implement `AsWidget` so the compiler enforces the supertrait chain.

### `#[derive(Object)]` with field attributes `#[prop(...)]`, `#[signal]`

Generates property + signal metadata and partial `impl Object`. Must be combined with `#[object_impl]` to produce a complete `impl Object`.

`#[prop]` variants:
- `#[prop]` — readable + writable, no notify
- `#[prop(notify = signal_name)]` — write calls `self.signal_name.emit(...)`
- `#[prop(read_only)]` — only readable via `read_property`
- `#[prop(stored = false)]` — excluded from serialization metadata
- `#[prop(designable = false)]` — hidden from visual designer tools
- `#[prop(user)]` — marks primary user-facing property
- `#[prop(constant)]` — never changes; implies no notify

`#[signal]` on a `Signal<Args>` field: extracts argument types for `SignalMeta`.

Outputs (in a hidden module):
- `__PROPS__{TypeName}`: `&'static [PropertyMeta]`
- `__SIGNALS__{TypeName}`: `&'static [SignalMeta]`
- Partial dispatch fns: `__read_property`, `__write_property`, `__connect_signal_dynamic`
- Helper: `__super_meta()` → `Option<&'static MetaObject>`

### `#[object_impl]` with method attribute `#[slot]` and `#[invokable]`

Applied to an `impl` block. Generates method metadata and the complete final `impl Object`.

- `#[slot]` — method callable as slot and via `invoke_method`; also appears in `MethodMeta`
- `#[invokable]` — method callable via `invoke_method` but not a slot (no connection target)

Outputs:
- `__METHODS__{TypeName}`: `&'static [MethodMeta]`
- `__invoke_method` dispatch fn
- `static META_{TypeName}: OnceLock<MetaObject>` — assembled from property + signal + method arrays
- Final `impl Object for TypeName` — delegates to generated fns

### `#[derive(MetaEnum)]`

Applied to a plain Rust `enum`. Generates `EnumMeta` and `EnumEntry` list; registers enum type in `Value::Custom` conversions.

## Out of scope

- Runtime-specific code in macros (macros emit code that calls quartzite-core APIs)
- Python-specific code generation (deferred)
- `#[derive(Extend)]` on enums or tuple structs (named fields only)

## Deferred

- `#[prop(stored = false)]` with custom getter/setter closure | needs design decision on how closures are stored in static context
- `#[object_impl]` on multiple impl blocks for one type | single impl block only for now

## Key decisions

| Question | Decision |
|---|---|
| Macro name for hierarchy | `#[derive(Extend)]` |
| Root marker | `#[root]` attribute on the struct |
| Base field marker | `#[base]` attribute on exactly one field |
| Mixin field marker | `#[mixin]` attribute; leaf trait only, no ancestor propagation |
| Trait naming convention | `As{TypeName}` — e.g. `AsWidgetBase` → `AsWidget` after stripping `Base` suffix (TBD: strip or keep?) |
| Two #[base] fields | Compile error with clear message |
| Missing #[base] without #[root] | Compile error suggesting to add one or the other |
| MetaObject assembly location | `#[object_impl]` — only it can see all three pieces |
| OnceLock for MetaObject | Yes — avoids static mut; safe lazy init |

## Technical constraints

- `quartzite-macros` is a `proc-macro = true` crate; cannot re-export types
- Macros work on syntax (TokenStream) only; cannot resolve trait bounds of other types
- All generated code must reference `::quartzite_core::` paths (not `crate::`)
- Macro crate depends on: `syn`, `quote`, `proc-macro2`
- Ancestor propagation uses naming convention (`As` prefix + type name), not type resolution

## Acceptance Criteria

| # | Criterion |
|---|-----------|
| AC1 | `#[derive(Extend)] #[root] struct Foo { id: u32 }` generates a trait `AsFoo` with `fn foo(&self) -> &Foo` and impl for `Foo` |
| AC2 | `#[derive(Extend)] struct Bar { #[base] foo: Foo, x: i32 }` generates `impl AsFoo for Bar` delegating to `self.foo` |
| AC3 | Two `#[base]` fields on one struct produces a compile error |
| AC4 | `#[derive(Extend)]` with no `#[root]`, no `#[base]`, no `#[mixin]` produces a compile error |
| AC5 | `#[mixin]` field generates only the leaf trait impl (not ancestor impls) |
| AC6 | `#[derive(Object)]` with `#[prop(notify = changed)] count: i32` generates `read_property("count")` returning `Value::Int` and `write_property("count", Value::Int(n))` updating `self.count` and emitting `self.changed` |
| AC7 | `#[derive(Object)]` with `#[prop(read_only)] val: i32` makes `write_property("val", _)` return `false` |
| AC8 | `#[object_impl]` assembles `MetaObject` accessible via `obj.meta_object()` with correct `class_name` |
| AC9 | `invoke_method("slot_name", &[Value::Int(1)])` on a type with `#[slot] fn slot_name(&mut self, x: i32)` calls the method with `x = 1` |
| AC10 | `connect_signal("sig_name", callback)` on a type with `#[signal] pub sig_name: Signal<(i32,)>` registers and later invokes the callback on emit |
