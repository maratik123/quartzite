# signals-blocked: typed emit wrappers with signals_blocked guard

**Source:** GitHub issue #34
**Date:** 2026-05-02

## Scope

1. `ObjectBase`: add private `signals_blocked: bool` field; add `block_signals()`, `unblock_signals()`, `signals_blocked() -> bool` methods (all `#[inline]`, with doc comments and `# Examples`)
2. `#[derive(Object)]` codegen: emit an `impl TypeName` block with `pub fn emit_<signal>(&mut self, arg0: T0, ...)` per `#[signal]` field; check `if self.object_base().signals_blocked() { return; }` before `self.<signal>.emit(&(arg0, ...))`
3. `write_<prop>` codegen: wrap the notify emit in the same `signals_blocked()` guard
4. Integration tests in `quartzite-macros/tests/object.rs`: block_signals suppresses slot calls; unblock_signals restores; property notify also suppressed

## Out of scope

- Changes to `Signal::emit` itself (tracked in #38)
- Serialization of `signals_blocked` state (tracked in #39)
- Python interop (deferred plan)

## Deferred

- Enforcing the check at `Signal` level rather than codegen level | requires API redesign (#38)

## Key decisions

| Question | Decision |
|---|---|
| `signals_blocked` field visibility | Private; exposed via `block_signals()` / `unblock_signals()` / `signals_blocked()` |
| `emit_<signal>` argument style | Individual flattened args (e.g. `emit_value_changed(&mut self, v: i32)`) |
| How codegen accesses the flag | `self.object_base().signals_blocked()` via `AsObject` trait — works for root and derived types |
| Where `emit_<signal>` wrappers live | `impl TypeName` block generated by `#[derive(Object)]` (outside the hidden module) |

## Technical constraints

- `#![deny(missing_docs)]` in all crates — every new public item needs a doc comment + `# Examples` block
- `#[inline]` on all new simple non-generic functions
- `cargo clippy -- -D warnings` must pass
- `cargo build -p quartzite --no-default-features` must compile (no_std path)

## Acceptance Criteria

| # | Criterion |
|---|-----------|
| AC1 | `ObjectBase::block_signals()` sets the flag; `unblock_signals()` clears it; `signals_blocked()` returns the current value |
| AC2 | `#[derive(Object)]` generates `pub fn emit_<signal>(&mut self, arg0: T0, ...)` for each `#[signal]` field |
| AC3 | Calling `emit_<signal>` when `signals_blocked()` returns `true` does not invoke any connected slot |
| AC4 | Calling `emit_<signal>` when `signals_blocked()` returns `false` delivers normally |
| AC5 | `write_property` with a notify-signal does not emit the notify signal when `signals_blocked()` is true |
| AC6 | Codegen unit test verifies `emit_<signal>` wrapper appears in output and contains the `signals_blocked` guard |
| AC7 | All existing tests remain green; `cargo clippy -- -D warnings` and doc gate pass |
