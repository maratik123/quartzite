# Widget System

**Source:** AI design dialogue (tmp/qt_01..14.log)
**Date:** 2026-05-01
**Tracked in:** https://github.com/maratik123/quartzite/issues/46

## Scope

Implement `quartzite-widgets` crate. Depends on quartzite-core, quartzite-geometry, quartzite-events, quartzite-runtime, quartzite-macros.

### WidgetBase

```
#[derive(Extend)] #[root]
pub struct WidgetBase {
    #[base] object: ObjectBase,
    geometry: Rect,
    visible: bool,
    enabled: bool,
    focus_policy: FocusPolicy,
    size_policy: SizePolicy,
    cursor: CursorShape,
    font: Arc<Font>,
    palette: Arc<Palette>,
    layout: Option<ObjectId>,
    event_filters: Vec<ObjectId>,
    pending_update: bool,
    min_size: Size,
    max_size: Size,
}
```

### AsWidget + WidgetExt

`AsWidget: AsObject` generated by macro from `WidgetBase`.

`WidgetExt` blanket trait on all `AsWidget` types:
- `geometry()`, `set_geometry(Rect)`, `pos()`, `size()`, `resize(Size)`, `move_to(Point)`
- `show()`, `hide()`, `is_visible()`, `set_visible(bool)`
- `is_enabled()`, `set_enabled(bool)`
- `update()` — marks pending repaint
- `size_hint() -> Size` (default: Size::zero())
- `minimum_size() -> Size`, `maximum_size() -> Size`
- Lifecycle hooks (default no-op, override in impl):
  - `paint(&self, painter: &mut dyn Painter)`
  - `on_resize(&mut self, size: Size)`
  - `on_show(&mut self)`
  - `on_hide(&mut self)`
  - `on_mouse_press(&mut self, event: &MouseEvent)`
  - `on_mouse_release(&mut self, event: &MouseEvent)`
  - `on_key_press(&mut self, event: &KeyEvent)`
  - `on_key_release(&mut self, event: &KeyEvent)`
  - `on_focus_in(&mut self)`
  - `on_focus_out(&mut self)`

### Layout System

- `Layout` trait: `add_widget(ObjectId)`, `remove_widget(ObjectId)`, `set_geometry(Rect)`, `size_hint() -> Size`, `minimum_size() -> Size`
- `BoxLayout` — horizontal or vertical stacking; spacing, margins, stretch factors
- `GridLayout` — rows × columns; cell spanning

### Concrete Widgets

- `Label` — `#[prop] text: String`, `#[prop] alignment: Alignment`
- `Button` — `#[prop(notify = text_changed)] text: String`, `#[prop] checkable: bool`, `#[prop] checked: bool`; signals: `clicked(bool)`, `text_changed(String)`, `toggled(bool)`; slots: `click()`, `set_text(String)`, `set_checked(bool)`
- `LineEdit` — `#[prop(notify = text_changed)] text: String`, `#[prop] placeholder: String`, `#[prop] read_only: bool`; signals: `text_changed(String)`, `return_pressed()`; slots: `set_text(String)`, `clear()`
- `TextEdit` — multi-line; similar to LineEdit plus `#[prop] plain_text: String`
- `ScrollArea` — scrollable container; `#[prop] widget: Option<ObjectId>`, `#[prop] h_scroll_policy`, `#[prop] v_scroll_policy`
- `Container` — generic layout container with no visual chrome

## Out of scope

- ComboBox, SpinBox, Slider, ProgressBar (deferred to v2)
- Platform-native rendering (uses `quartzite-paint` Painter abstraction)
- Accessibility

## Deferred

- ComboBox, SpinBox, Slider, ProgressBar | not enough context to spec
- Menu / MenuBar | needs window/action system
- Dialog system | needs modal event loop
- Tooltip / ToolBar | low priority

## Key decisions

| Question | Decision |
|---|---|
| Widget lifecycle hooks | Default no-op methods in `WidgetExt`; concrete types override in `#[object_impl]` block |
| `WidgetBase` as `#[root]` | Yes — `#[derive(Extend)] #[root]` generates `AsWidget` trait |
| Layout stored by | ObjectId reference inside WidgetBase |
| Widget children | Stored in `ObjectBase.children` (ObjectId vec); WidgetBase does not duplicate |
| `size_hint` default | `Size::zero()` — caller must set minimum_size or layout won't allocate space |

## Technical constraints

- `quartzite-widgets` must not depend on any platform-specific crate
- `Painter` used in `paint()` is a trait from `quartzite-paint`; widgets depend on that crate
- Widget construction must go through `ObjectTree::insert` — widgets cannot live outside the tree

## Acceptance Criteria

| # | Criterion |
|---|-----------|
| AC1 | `Button` created with text "OK" has `read_property("text") == Value::String("OK".into())` |
| AC2 | `Button::click()` emits the `clicked` signal with `checked = false` when not checkable |
| AC3 | Writing `Value::String("Cancel".into())` to `Button` property `"text"` updates `self.text` and emits `text_changed` |
| AC4 | `button.show()` sets `widget_base().visible == true`; `hide()` sets it to `false` |
| AC5 | `BoxLayout` with two widgets distributes total rect width equally when both have equal stretch |
| AC6 | `GridLayout` places widget at (row=0, col=1) inside the correct cell rect |
| AC7 | `WidgetExt::update()` sets `widget_base().pending_update == true` |
| AC8 | `Label` with `text = "hello"` has `meta_object().class_name == "Label"` |
| AC9 | `LineEdit` emits `text_changed` when `set_text("new")` is called with a different value |
| AC10 | A widget with `min_size = Size::new(100, 50)` returns that from `minimum_size()` |

## Open questions

- Should `WidgetExt::paint` be called directly or only via a Painter-dispatch mechanism in the EventLoop?
- How are event_filters (installed via ObjectId) resolved to concrete `EventFilter` trait objects at dispatch time?
- Should `Container` be a separate type or just `WidgetBase` with a layout attached?
